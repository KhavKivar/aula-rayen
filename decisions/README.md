# Decisiones

Carpeta para registrar las decisiones importantes del proyecto en formato Markdown.

## Convención

- Un archivo por decisión: `NNNN-titulo-corto.md` (ej: `0001-orm-drizzle.md`).
- Idioma: español para el contenido, inglés para nombres técnicos de dominio.
- Cada decisión sigue la plantilla en `0000-template.md`.

## Formato mínimo

1. Contexto
2. Decisión
3. Alternativas consideradas
4. Consecuencias
